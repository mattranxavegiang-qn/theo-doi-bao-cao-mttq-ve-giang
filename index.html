Đang chờ cấu hình URL Web App

Cần cấu hình URL Google Apps Script

Mở file index.html, tìm dòng const WEB_APP_URL = 'https://script.google.com/macros/s/AKfycbybZ_7K1hFsFLvBsX6djGvzkBMMnCQYPe1-Dlf4fLTNd2arDGNsKEuO3NW8l9Z_SLkl/exec'; và thay phần trong dấu nháy bằng URL Web App đang hoạt động, thường kết thúc bằng /exec.

Không dùng URL trang chỉnh sửa Apps Script hoặc URL Google Sheets. Sau khi sửa, lưu file và tải lên kho GitHub Pages.
